# DeepSeek Harness Plugins

个人 DeepSeek Harness 插件开发仓库，用于管理插件源码、开发文档与实验。

## 当前状态

仓库初始化阶段，尚未包含插件实现或构建配置。

## 目录规划

后续按需创建以下目录：

```text
plugins/    # 各插件的源码与独立说明
shared/     # 插件间复用的代码
examples/   # 使用示例
docs/       # 开发笔记与设计文档
```

## 开发约定

- 每个插件单独维护用途、配置项、开发方式与兼容版本说明。
- 开发前核对当前安装版本的 DSH 文档与运行时接口，不依赖未经验证的 API。
- 依赖、构建和测试命令在引入相应工程配置后记录。
- 提交源码与依赖锁文件，不提交依赖目录、构建产物、运行时数据或密钥。
- 本地环境变量放入 `.env` 等忽略文件；可提交不含真实凭据的 `.env.example`。

## 安全

即使仓库为私有，也不要提交访问令牌、个人配置、会话记录或其他敏感数据。
